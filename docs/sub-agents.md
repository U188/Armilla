# 主代理与子代理

设置 → 模型功能 → 子代理，可配置最多两个模型引用。聊天当前模型始终为主代理。
长按输入栏模型选择器打开本会话的自动委派开关，默认开启；未配置子代理时不暴露委派工具。
新会话继承发送前草稿开关，之后各会话独立；更改在下一次运行生效。

主代理通过 delegate_task 发起自包含任务（task、可选 context、worker），立即取得 task_id；
通过 get_task_result 获取 running/completed/failed/cancelled/timed_out，或 cancel_task 取消。
结果标记 review_required，主代理负责核验证据、处理分歧和最终答复。
子代理只收到主代理明确提供的任务上下文，不复制聊天历史、持久记忆或助手指令。

运行时最多两个并行工作线程，每次主代理运行最多 16 项任务，每项最多 180 秒。
结果上限 16,000 字符，截断有提示。任务 ID 仅在所属运行有效。
父任务停止或结束时关闭协调器并取消所有子任务；晚到结果不能覆盖已取消状态。
子任务失败只返回脱敏失败状态，由主代理接手。

只读策略同时过滤工具目录和拦截执行：只提供显式列出的查询工具、read_file/list_directory、
skills 读取和 memory_get；权限仍受本次主运行与当前设备开关约束。
不开放 terminal/run_command、GUI、browser_use、MCP、写入、安装、发送或委派工具。
工具权限不会仅靠提示词约束。子代理结果按敏感工具结果处理，原始内容不写入持久会话。
主代理审核后组织的最终答复仍按正常会话保存。

当前不跨运行恢复子任务；重启/继续任务时主代理需重新委派。没有共享浏览器子标签或可写工作区。
测试覆盖并行上限、所属运行隔离、取消/结束传播、超时、结果边界、失败脱敏与目录/执行双重限制。
